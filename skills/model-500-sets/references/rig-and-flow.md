## Tempo
- A +/-6% range moves a 128 BPM track by up to 7.7 BPM. Mark: Math.
- About 5.9% tempo change equals one semitone if key lock is off. Mark: Math.
- Flag jumps over 6% between neighbors. The user can widen the range or use a hard cut. Mark: Advice.
- Earlier sets may have used Sync on. Ask the user for each new set. Mark: Note.

## Key: Camelot wheel

Key clash is a flag for the user's ears, not a ban. Key Sync can shift a track. Whether that sounds right is the user's call.

## Transition types (Advice)
- Long blend: both tracks have long, simple intros and outros. Needs close BPM and key.
- Echo out: use Beat FX Echo on the outgoing track, then start the next track alone. A finished set can end this way.
- Hard cut: use for large BPM or key jumps.
- Drop over a gap: fire an IGNITE clip across a break. Check clip length against the bars.

Give transition times from data the user can verify. Without waveform access, ask the user for intro and outro bar counts.

## Cue plan (Advice)
| Hot cue | Purpose |
|---|---|
| A | First beat |
| B | Mix-in point |
| C | Main break |
| D | Drop or peak |
| E | Mix-out point |
| F to H | Free, for the user |

The letters are a proposal, not the user's habit. Ask the user first. Set cues only on bought files where possible (Note: buy before setting cues).
